# F6 Launcher 1.4.8.2

F6 Launcher 是基于 HoYoShade Hub 修改的非官方分支。本版包含 1.4.8.1 之后的启动、插件导入、NR 选择和覆盖包改进。

## 启动与配置准备

- 统一活跃游戏进程识别，忽略已退出的零线程残留记录；确有游戏运行时阻止重复启动，并同步运行状态和关闭入口。
- 随应用提供保留原版权与许可的 F6ShadeInjector，修复原注入器在就绪前反复处理退出记录导致游戏迟迟不能启动的问题；不强退已有游戏。
- 减少启动前重复的 NR 全文件读取、配置和插件包同步，把文件准备移出界面线程，并记录各阶段耗时。
- 修复帧率解锁 CLI 会话过早退出及资源退休时序；附加成功后保持会话到对应游戏进程退出。成功附加不代表实际帧率已验收。

## 插件、OptiScaler 与 NR

- 本地 addon 拖入安装显示实际处理进度，避免进度条一直停在 0。
- NR 版本列表在下拉关闭后更新，选择时延后文件操作，保留插件卡片与焦点，减少弹出层更新导致的闪退风险。
- 兼容 F5 下载资产的新旧文件名；旧目录规则失配时明确选择文件，不猜选 Optional 或 Patch 包。
- 下载清单和连接等待可取消、有限时；错误显示到卡片和全局状态，避免点击下载后长时间无反馈。
- 单个 OptiScaler 或模块导入只整理本次安装目录的 NR 硬链接，保留完整 SHA256 校验与失败回滚，避免扫描整个库。

## 覆盖包

- 支持按游戏导入并绑定包内 INI，已有 Opti 配置也能切换到覆盖包指定的完整配置。
- 每个动作步骤分别勾选；指定目录放置文件的动作以红色显示。弹窗打开满 3 秒后才可点击“应用”。
- 文件放置支持目标目录、重命名、SHA256 和覆盖控制；替换前独立备份，避免写穿已有硬链接。
- 增加 reset_launch_options 动作，清空当前游戏的附加启动项和模块选择，覆盖 XXMI、Rocket、Starward、Blender 等，再由包显式启用所需组件；不改其他游戏和全局模块开关。
- 同为 1.4.8.2 的早期测试构建可能缺少新动作，使用新覆盖包前请更新到本次正式版。

## 发行包

GitHub 仅提供普通便携 ZIP；Full 完整包单独交付。不捆绑 F5/F6 覆盖包、用户数据库、游戏配置、下载缓存或日志。
包最外层仅提供 F6Launcher.exe，内部保留旧更新器需要的兼容入口。两种包均包含原始 LICENSE、Starward_LICENSE 和 NOTICE.md。

本版的离线回归、发行包内容和旧更新器兼容性由发布检查记录验证；未进行本次正式版的真实 GUI 或游戏验收。
