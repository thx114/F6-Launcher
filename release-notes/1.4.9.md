# F6 Launcher 1.4.9

F6 Launcher 是基于 HoYoShade Hub 修改的非官方分支。

- **保留游戏画质设置。** 启动游戏时不再自动覆盖渲染精度；精度调整由用户在游戏设置页点击「应用」后写入。
- **游戏轻量模式。** 游戏启动准备完成后，由原生托盘进程接管会话监测，主界面退出以释放内存。最后一局退出后在后台归档日志、保存配置，不会自动弹回主界面。进程仍在但没有窗口时会单独显示，避免重复启动。可在设置中关闭轻量模式。
- **覆盖包按导入批次应用。** 默认 INI 和预设完成首次应用后，后续启动会保留用户的修改；未确认的动作可稍后再应用，纯 GamePack 也可导入。文件被占用时会报错并保留原有的应用批次，关闭占用后可重新导入。
- **Rocket 模组预览。** 优先显示模组自己的封面；没有封面时，可使用本地 Rocket 对应角色的头像。
- **OptiScaler 和模块管理。** 支持 AMD DLSS5 NR 30X 的 7z 发行包；改善 Opti 与 NR 选择布局，避免把手动导入的通用 `version.dll` 错认成某个具体模块。
- **页面响应和更新。** 优先使用本地目录及游戏背景缓存，可在主窗口查看后台请求。便携版成功打开新版后会回收旧应用目录，保留一个回退版本和仍在使用的版本。

GitHub 提供 Windows x64 普通便携 ZIP。解压后运行 `F6Launcher.exe`；已有支持的便携版本也可在启动器内检查更新。安装包保留原始 `LICENSE`、`Starward_LICENSE` 和 `NOTICE.md`，不附带 Full、游戏覆盖包或用户数据。

本次发行执行离线回归、原生后台辅助进程检查、包内逐文件校验及新旧更新器安装验证；未进行本次正式包的真实页面或游戏验收。
