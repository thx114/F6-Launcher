# F6 Launcher 1.4.8.1

F6 Launcher 是基于 HoYoShade Hub 修改的非官方分支。本版延续 1.4.8 的功能与修复。

## 覆盖包与首次配置

- 修复旧覆盖包首次安装时缺少 ReShade.ini 导致配置动作失败的问题：优先使用宿主模板，模板尚未生成时创建包含基础搜索路径的主配置。
- 显式 INI 写入动作支持创建目标 INI，只修改覆盖包指定的键，保留已有注释及其他参数；未请求的 NR 配置文件不会自动生成。
- 配置失败时显示实际目标路径和原因。对上次中断的 INI 动作，用户确认后可仅重试当前步骤，已完成的步骤保持记录。

## 缓存与日志

- 过滤 OptiScaler 运行载荷中的转储、跟踪及历史日志，减少缓存与后续游戏会话中的无用文件累积。
- 会话日志收集按本局启动时间检查文件修改时间，避免把旧 ReShade / FSR 日志归入新一局；转储文件归档到日志目录。

## 便携包

- 普通便携包最外层仅提供 F6Launcher.exe，移除重复的 HoYoShadeHub.exe 入口。
- 主程序、RPC、协议注册及重启入口统一优先使用 F6Launcher.exe，并兼容旧安装路径。
- 包内保留原始 LICENSE、Starward_LICENSE 和 NOTICE.md。

本次 GitHub 仅提供普通便携 ZIP，不附带 Full 包或 F5 覆盖包。相关 INI、动作重试和便携入口离线回归共 248 项通过；未进行本版 UI 或游戏实测。
