# HoYoShade Hub 1.4.7

- 覆盖包可为每款游戏分别选择 OptiScaler NR，新增 `set_opt_nr` / `set_optiscaler_nr` 动作；支持随包 DLL 的离线 SHA256、x64 PE 和已知内容指纹校验。
- NR 版本库与每游戏运行目录使用严格硬链接；覆盖包在游戏缓存所在卷暂存，修复系统临时目录与便携安装不同盘时导入失败。
- 新增 `set_opt_config` 的 `if_missing:true`：保留已有游戏 profile 与配置绑定，只初始化缺失配置。官方 profile 作为权威来源投影至独立 NR runtime。
- 随包更新原神 v4 预设 A / 1080p5000 的 NR 指纹和下载目录，兼容 F5 三游戏覆盖包；崩铁、绝区零可独立使用 `310.9.16-SF`。
- 改进原始 ZIP 拖入识别、页面加载等待及错误提示，并收录带目标进程/窗口身份约束的 CLI 诊断操作和旧动作清理维护。

本次发布的 `HoYoShadeHub_Portable_1.4.7_x64.zip` 是启动器普通便携更新包，保留既有用户配置；F5 游戏覆盖包单独导入。程序包不包含 HoYoShade 框架、F5/F6 Opt 构建或大型 NR DLL。

已完成 Release 构建、ZIP 内容校验及隔离导入/动作回归。游戏视觉、深度、NR/FG 和性能不在本次发布验证范围内。
