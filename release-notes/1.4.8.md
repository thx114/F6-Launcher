# F6 Launcher 1.4.8

本版本起产品更名为 **F6 Launcher**，由 thx114 独立维护，是基于 HoYoShade Hub 修改的非官方分支，与上游官方无隶属关系。

- 使用独立 F6 图标；关于页、欢迎页和窗口标题显著标注非官方分支，保留原作者哆啦D夢|DuolaD 和 Starward 的来源说明。
- 普通便携包根目录及应用目录均附带原始 `LICENSE`、`Starward_LICENSE` 和 `NOTICE.md`，构建/打包新增许可与图标校验。
- 启动器反馈、版本检测、发布与元数据指向本仓库。移除上游私有镜像 API；旧私有线路设置迁移为直连，并阻止缓存 URL 和重定向重新使用已停用服务。可手动选择独立公共 GitHub 代理。
- 全局插件页优先显示本地缓存，耗时磁盘检查移到后台；远端目录并行获取并合并重复请求。
- OptiScaler 卡片内编辑下拉框、开关和配置不再误选或启用构建；文件操作异步串行执行。
- NR/DLL 读取、SHA256 校验和硬链接切换移到后台，增加忙碌反馈和过期结果保护，保留内容身份校验及硬链接失败即停止的行为。
- 移除隐藏主窗口时的强制完整 GC，延后窗口激活刷新并增加恢复耗时日志。

本次发行只提供 `F6Launcher_Portable_1.4.8_x64.zip`，解压后运行 `F6Launcher.exe`；更新现有便携安装时解压到原目录。包不携带 HoYoShade 框架，不覆盖已有用户数据及游戏配置。许可与来源说明已在包内，无需额外下载附件。

内部 `HoYoShadeHub.exe`、命名空间和既有数据目录保留，方便兼容历史安装与覆盖包；产品名称、图标和支持渠道已独立。本次不发布 Full 包或 F5 覆盖包。

本次完成编译与包内容/哈希检查；未运行启动器 UI、CLI 或游戏测试，实际体验由用户验收。
