# HoYoShade Hub 1.4.7.1

- 修复全新安装首次导入覆盖包时，动作确认入口遗漏暂存包子目录，导致包内 `NR/nvngx_dlssnr.dll` 丢失。导入确认与游戏页同步共用完整目录迁移，失败保留源内容并停止动作。
- 新增 `require_launcher_version` 动作（`minVersion` 指定最低版本）。执行同包任何动作前检查启用动作中的版本要求；版本不足时提示更新并阻断后续动作。版本要求每次重查，不被 once 账本跳过。
- 补齐 `set_opt_nr` 的中文动作说明；动作失败或被阻断时显示警告，不再一律报告绿色完成。

新安装使用 `HoYoShadeHub_Portable_1.4.7.1_x64_Full.zip`；现有安装通过普通便携更新包升级。Full 包含 HoYoShade 框架、滤镜和材质，不捆绑 F5/F6 Opt 或大型 NR DLL。

单独交付的 F5 覆盖包更新为 `[原铁绝]F5_v4.2.zip`（GitHub 附件名 `F5_v4.2.zip`），继续兼容本次启动器 **1.4.7.1**，不需要另一个启动器版本。覆盖包使用已有动作关闭当前游戏的 XXMI、模块、HoYoShade、OpenHoYoShade、帧率解锁和旧 Opt 开关，再启用 Opt、选择 F5，导入并自动应用对应游戏配置（已有 profile 也会切换），最后选择各自 NR。

现有启动器动作未提供关闭 Rocket、Starward、Blender 或跳过 HoYoShade 注入器的接口；这些项若已勾选，需要手动取消。v4.2 只修改包内动作和交付元数据，冻结 Opt/NR DLL 与包内 INI 文件内容不变。

使用 1.4.7.1 直接重新导入 v4.2 并确认动作即可。此前失败的导入可能已丢失 NR 子目录，重新导入可恢复包内文件。旧 v4.1 附件保留供历史回溯。

按用户要求，本次新增版本要求后的交互、导入与游戏验证交由用户执行；仅完成编译及打包内容校验，未自动部署到本机启动器。
