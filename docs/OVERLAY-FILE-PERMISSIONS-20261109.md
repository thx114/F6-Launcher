# 覆盖包指定文件放置与逐项确认

测试构建继续使用 1.4.8.2。每个 `steps` 项目显示一个独立勾选框；动作组只保留标题。指定目录放文件的项目、来源和目标详情均以红色显示。

确认弹窗实际打开后开始 3 秒倒计时，按钮显示“应用（3 秒）”并禁用，满 3 秒变为“应用”。计时采用单调时钟；提前点击或按回车不能绕过。关闭再打开重新计时。“全部不要”和“下次再说”可立即点击。

勾选结果随当前 `auto.json` SHA256 保存。取消的步骤在导入、启动前执行和显式执行包动作时都会跳过，不登记 pending/success。已完成的步骤保留 once 状态，完整执行计划和原步骤序号不变。兼容旧版按整组禁用的同意记录；包内容改变或重新导入时重新确认。

## copy_file

`copy_file`（同义名 `place_file`）每次指定一个文件。多个文件写成多个步骤，用户可以分别勾选。文件须放在相应游戏的 GamePack 目录内，与 `auto.json` 一起导入。

```json
{
  "actions": [{
    "name": "安装指定文件",
    "runOnLaunch": true,
    "steps": [
      {
        "action": "copy_file",
        "file": "payload/custom.ini",
        "directory": "D:\\MyGame\\Config",
        "name": "custom.ini",
        "overwrite": true
      },
      {
        "action": "copy_file",
        "file": "payload/second.ini",
        "target": "game",
        "directory": "Config"
      }
    ]
  }]
}
```

| 字段 | 含义 |
| --- | --- |
| `file` | 必填，包内相对文件路径，禁止绝对路径和 `..`。 |
| `directory` | 必填，目标目录；可以是绝对路径，也可以是相对目标根目录的路径。`"."` 表示根目录本身。 |
| `target` | 相对目录的根：`game`（默认，当前游戏）、`launcher`（启动器数据/便携根）、`shade`（HoYoShade 宿主根）。绝对目录不使用此字段。 |
| `name` | 可选，目标文件名；默认使用源文件名，禁止包含目录。 |
| `sha256` | 可选，源文件的完整 64 位十六进制摘要，不匹配时停止。 |
| `overwrite` | 可选布尔值，默认 `true`；`false` 时拒绝替换不同内容的已有目标。 |

普通文件先复制到目标目录临时文件，校验完整 SHA256，再替换目标，避免写穿旧硬链接。替换前，原文件独立备份为包内 `.file-backups/<随机标识>.bak`，旁边的 `.bak.json` 记录目标路径、原 SHA256 和备份时间。相同内容保留现有文件。源或目标名为 `nvngx_dlssnr.dll` 时必须建立并验证同卷硬链接，失败不降级为复制。

不支持路径穿越、设备路径和包含重解析点的路径；不请求管理员权限。路径不可写、目标被锁、摘要不符等错误会停止当前动作及后续批次，保留 once pending 供核验，不自动重试可能已部分完成的文件操作。

## 验证

`pack-permission-tests` 验证精确计时、schema 1/2 同意记录、逐步骤原始身份与 once 行为、取消步骤的 INI 前置条件，以及文件创建、改名、覆盖备份、原硬链接副本保护、摘要/路径/锁定失败、NR 硬链接。

本地构建与部署证据位于 `artifacts/pack-file-permissions-20261109`。UI 和游戏效果由用户实测。
