# F6 5.2 覆盖包：内置滤镜安装

从 1.4.9.2 起支持 `install_opt_filters`。使用该动作的覆盖包应将最低启动器版本设为 1.4.9.2。

## 离线载荷布局

现有 `optiscaler` target 支持整棵目录。推荐直接把配套核心、配置、着色器和纹理放在构建内，并列入 filelist.json 的大小与 SHA256 清单，无需额外动作：

```text
OptiScaler/F6/v5.2/
  OptiScaler.dll
  HoYoShade/
    ReShade64.dll
    ReShade.ini
    Presets/BeforeSR-Default.ini
    reshade-shaders/Shaders/...
    reshade-shaders/Textures/...
```

保留 iMMERSE Launchpad、MXAO、MartysMods 头文件和纹理的子目录。使用 F6 配套核心和相对路径 INI，空预设写 `Techniques=`。

## 安装动作

从当前游戏 GamePack 内的滤镜目录安装到指定构建：

```json
{"action":"install_opt_filters","build":"F6/v5.2","source":"package","directory":"HoYoShade","once":true}
```

或复用启动器已安装的 HoYoShade：

```json
{"action":"install_opt_filters","build":"F6/v5.2","source":"launcher","once":true}
```

package 为默认来源；directory 相对当前游戏 GamePack，默认 HoYoShade。launcher 来源通过全局框架定位（含用户手动指定目录）取文件，不携带机器绝对路径。框架或着色器未装时会明确报错，需要先在设置→管理中安装，再重新应用动作。launcher 来源复制当前核心，要求特定核心版本的发行包应使用完整离线载荷。

指定构建必须已安装。动作放在最低版本检查之后、重置启动项之前；构建及滤镜均齐全后，再执行原有的选择 F6、关闭独立 HoYoShade/OpenHoYoShade 注入等动作。

安装器只取 ReShade64.dll、Shaders、Textures、Presets 和 ReShade.ini，不复制独立注入器、addon、日志或账本。三项 GENERAL 路径改为相对路径，其余配置保留，缺失时补上默认深度定义和空预设。独立暂存后合并替换，源文件不变。

启动准备会把完整 HoYoShade 目录放到实际 F6 DLL 旁边；已有 OptiRuntime 的着色器/纹理会刷新，其 ReShade.ini 和预设继续保留。F6 在 LOCALAPPDATA 下保存的个人预设不受影响。
