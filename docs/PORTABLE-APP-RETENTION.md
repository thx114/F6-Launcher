# 便携应用版本回收

便携启动器仍由根目录 `version.ini` 选择 `app-*`。新 GUI 的 `MainView.Loaded` 成功执行后，延迟 10 秒在工作线程回收旧应用目录；外层启动壳、下载完成和部署脚本不会提前清理。

保留当前选中的运行版本、一个回退版本，以及进程映像仍位于对应目录的所有运行版本（包括轻量托盘、RPC 和注入辅助进程）。成功启动另一版本后，原当前版本成为回退版本。第一次采用本机制时，从完整的旧应用目录中按目录创建时间选择一个回退版本，不按可能共享的 EXE 修改时间排序。

状态位于便携根目录 `.hysx/portable-app-retention.json`。删除前先保存待回收列表，文件占用、只读或中途退出留下的部分目录在后续成功启动时继续尝试。无法确认启动器进程映像、`version.ini` 发生改变或更新正在解压时，推迟清理。

更新解压及其最终 `version.ini` 切换，与清理共用 `.hysx/portable-maintenance.lock` 独占文件锁。旧 GUI 在更新后继续运行时不会回收新选中的版本。

只处理便携根目录下具有版本名称和完整启动器载荷的 `app-*` 直接子目录，或本机制先前已记录的待回收目录。遇到重解析点不跟随；删除旧目录中的硬链接时只移除该路径，不修改共享内容或清除只读属性。不处理插件、OptiScaler、背景、缓存、日志、数据库及用户配置。

隔离验证：`dotnet run --project src/F6Launcher.Retention.Tests -c Release`。包括版本轮换、更新互斥、指针切换、硬链接和只读属性、重解析点、删除重试，以及实际辅助进程映像识别；不启动启动器 GUI 或游戏。
