# Opt 来源卡片与版本（2026-11-04）

## 身份与展示

- 卡片按 `OptiScalerBuild.SourceId` 分组，忽略大小写，不按显示名称或 DLL 版本猜测来源。不同来源仍各占一张卡片。
- 全局管理页一张卡片展示该来源所有已安装版本，不再为每个版本重复整张卡片和完整版本列表。
- 卡片摘要优先展示库当前选中版本；没有选中版本时沿用库既有顺序。刷新后的展开状态按来源保留。
- 搜索匹配所有已安装版本，隐藏卡片不影响 NR / 上采样依赖查找。

## 按版本的操作

- 每行独立保留全局可用开关、打开目录、重装和删除，持久化仍使用原 `sourceId/version` ID。分组不迁移配置，也不批量开关版本。
- 卡片摘要版本上的目录、删除、补充 NR 操作保持针对摘要所示目录；删除按钮明确标注版本作用域。
- 游戏 Opt 页面同样一来源一卡片，版本下拉独立于配置下拉；明确选择版本才切换游戏使用的构建。
- 切换版本后台读取该版本的配置与已展开的快捷项；失败时恢复旧版本选择，不将旧版本配置显示成新版本配置。
- 单选圈、标题和空白处仍可选择 Opt；编辑预设、NR 或快捷配置不触发构建选择。

## 交付边界

- 本地测试沿用 `1.4.8`，以构建时间和 SHA256 区分；本轮没有发布或替换 GitHub 发行。
- 编译、包内容核验和部署记录放在 `artifacts/opti-source-cards-20261104/`。
- 不自动启动启动器、CLI 或游戏测试，实际交互由用户验收。
