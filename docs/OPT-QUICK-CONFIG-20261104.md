# Opt 配置项与展开调整（2026-11-04）

## 配置入口

按维护者清单保留 13 项，顺序为：FG 帧生成、FGInput（帧生成输入）、FGOutput（帧生成输出）、NR 神经渲染、AdaMFG解锁（40系）、Ampere MFG 解锁（20/30系）、DX11 超分后端、DX12 超分后端、提前挂钩、深度反转、抖动抵消、NR 成品图、帧率上限。

移除 NR 工作精度、伪装 HAGS、NR 在超分之前运行、输出缩放四个 UI 入口。此前不展示的 SmoothMotion、HookOriginalNvngxOnly、AutoExposure 不再保留为隐藏描述子；描述子清单即实际显示清单。仅改变启动器入口，已有 INI 键和值不清除，不重置游戏配置。同步维护现有回归检查的清单数量和补节用例。

## 展开路径

- 展开状态立即变化，文件读取和 INI 解析在后台完成；读取期间保留收起/切换配置操作。只和本页写操作串行，不等待无关的全局 NR DLL 任务。
- 每行用 x:Load 只创建对应的一种编辑控件，不再创建三个控件后隐藏其中两个。
- 首次将值填入全部行后一次性设置 ItemsSource，避免 ObservableCollection 逐项追加触发重复模板创建与布局。收起后保留已创建编辑器，重新展开只刷新值。
- 本页停止使用需要强制 Measure 和逐帧 Height 布局的展开动画，沿用列表既有的兄弟卡片位移动画；其它页面动画不变。
- 异步读取验证页面代次、游戏、构建和当前配置，丢弃切页/换配置后的过期结果；读取和写入时编辑器不可提交。
- 新增 quick config 的 readMs / publishMs / rows 日志，仅记录排队读取和模型发布耗时，不代表完整 XAML 排版或视觉验收结果。

## 交付边界

本轮使用 1.4.8.2 本地验收版本区分运行文件，不恢复 1.4.8 对外发布，不上传 GitHub。由维护者自行操作 UI 与游戏验收；代理只编译、核验打包内容并部署，不启动启动器/UI/CLI/游戏测试。
