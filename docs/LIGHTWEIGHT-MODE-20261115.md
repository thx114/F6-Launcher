# F6 Launcher 轻量模式、缓存与后台请求（2026-11-15）

本轮测试继续使用 1.4.8.2。用户自行测试界面和游戏；本轮仅运行编译、离线检查和专用辅助进程，不启动或关闭游戏，也不操控现有启动器。

## 日志与 BG 原因

测试便携版的 `log/HoYoShadeHub_261115.log` 中，已缓存全局插件卡片显示约 48–59 ms，完整本地快照约 334–356 ms；模块后台读取约 177–320 ms，应用列表约 0.1–1.8 ms。激活后的 UI 排队曾达到 469–720 ms，GUI 私有内存约 361 MiB。这些数据属于旧进程，不能当作新构建实测结果。

ImageEx 0.1.0 在清空 PlaceholderSource 时会取消加载并切到 Unloaded。此前在图片打开 650 ms 后清空占位图，导致有效 BG 也被隐藏。本轮移除此操作，实际控件卸载时仍释放图片、视频及事件订阅。

切换游戏时先解码该游戏已有的本地背景，再更新远端元数据。背景清单保存到 `.hysx/backgrounds/<biz>.<language>.json`，有效期六小时；获取失败保留已有缓存。图片文件继续复用 `bg`，不重复下载。

## 本地目录与请求列表

- DLL 页面先读取 `.hysx/catalog/dll-components.json` 和本地运行时，再后台刷新过期清单；自动刷新按 24 小时节流，失败后保留清单并限制重试频率。
- 全局插件、模块、Opti 目录继续读取现有本地目录缓存。Opti 只读取每个来源当前显示版本的配置，其他版本保留在版本选择器内。
- 共用 HTTP 通道记录请求名称、去掉查询参数的地址、实际耗时及完成/失败状态。流式下载读完正文才结束计时。
- 主窗口右下角显示进行中的请求，点击展开最近记录。没有请求时保持紧凑。列表最多保留 12 条已完成记录，离页停止 UI 定时器。

## 进程与交接

`F6Launcher.BackgroundHost` 为 NativeAOT 原生程序，使用 Win32 托盘和命名管道，不加载 CLR、WinUI、WinForms 或 XAML。管道按当前用户和数据目录隔离。

GUI 等待启动准备、延迟注入和 FPS 附加完成后，先交出本局监测和快照，再停止托管 RPC 进程。后台确认接管后 GUI 进程退出，图片、页面、Win2D 和托管 UI 堆随进程卸载。设置中的“游戏轻量模式”默认开启。

后台持有 PID、创建时间与准确的进程句柄，沿用统一游戏存活判定。它持续处理游戏时长、会话日志和现有 FPS 远程资源生命周期。时长直接使用发行包已有的 SQLite 原生库，不创建托管时长进程。配置回写仅记录本局选中的 Opti 目录，不把日志发现目录当作可回写目录。

后台在游戏结束时启动无界面的收尾任务，完成原有的 profile/preset 回写、日志摘要及转储归档后直接退出，托盘继续待命。只有用户点托盘或主动打开启动器才恢复界面；恢复期间保留同一个会话目录，用户主动打开后不会立即再次自动卸载。最小化统一进入托盘。
